Task: a FILE-MAILBOX BRIDGE so a Cursor agent can delegate work to Forge (the local agent), mirroring the existing Claude->Cursor bridge. Look at ~/.local/bin/bridge (bash) first: it keeps a mailbox at <repo>/.agent-bridge/inbox/<name>/*.md (frontmatter from/to/subject/sent, then body) and archives read mail in .agent-bridge/archive/. Forge becomes mailbox "forge"; Cursor is "cursor". So `bridge send cursor forge "subj" "task text"` must work with NO changes to that script, and Cursor reads the reply with `bridge read cursor`.

Watches inbox/forge via fs.watch PLUS a poll fallback; processes ONE task at a time, oldest filename first.
